# Architecture Decision Records

This directory stores decisions that affect MobileBIOS architecture or long-term maintenance.

Use one numbered Markdown file per decision. Each record should include:

- Status: Proposed, Accepted, Superseded, or Rejected
- Context and problem
- Decision
- Alternatives considered
- Consequences and trade-offs
- Date and related commits/issues
